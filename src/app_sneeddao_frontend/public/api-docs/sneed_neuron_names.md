# sneed_neuron_names

`sneed_neuron_names` is one of the six canisters of the Sneed DAO naming service. Public names of SNS neurons, unique per SNS.

| | |
|---|---|
| Production canister | `e46oa-kqaaa-aaaad-qmk2a-cai` |
| Staging canister | `rjmdp-paaaa-aaaad-ag6ma-cai` |
| Candid interface | [sneed_neuron_names.did](/api-docs/sneed_neuron_names.did) · [JavaScript IDL factory](/api-docs/sneed_neuron_names.did.js) |
| Source | [src/sneed_neuron_names](https://github.com/Snassy-icp/app_sneeddao/tree/main/src/sneed_neuron_names) |

The whole naming service is documented in one place: **[Sneed Names API](/api/sneed_names)** ([raw Markdown](/api-docs/sneed_names.md)). This canister's methods are in [section 5](/api/sneed_names#55-sneedneuronnames).

## Block types

This canister keeps an ICRC-3 activity log. Its block types are described in [Sneed Names, section 6: Activity log (ICRC-3)](/api/sneed_names#6-activity-log-icrc-3) ([block types](/api/sneed_names#block-types)).
