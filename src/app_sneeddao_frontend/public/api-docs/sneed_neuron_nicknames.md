# sneed_neuron_nicknames

`sneed_neuron_nicknames` is one of the six canisters of the Sneed DAO naming service. Each user's own labels for SNS neurons.

| | |
|---|---|
| Production canister | `es4di-raaaa-aaaad-qmk3a-cai` |
| Staging canister | `rhooh-uqaaa-aaaad-ag6na-cai` |
| Candid interface | [sneed_neuron_nicknames.did](/api-docs/sneed_neuron_nicknames.did) · [JavaScript IDL factory](/api-docs/sneed_neuron_nicknames.did.js) |
| Source | [src/sneed_neuron_nicknames](https://github.com/Snassy-icp/app_sneeddao/tree/main/src/sneed_neuron_nicknames) |

The whole naming service is documented in one place: **[Sneed Names API](/api/sneed_names)** ([raw Markdown](/api-docs/sneed_names.md)). This canister's methods are in [section 5](/api/sneed_names#56-sneedpidnicknames-and-sneedneuronnicknames).
